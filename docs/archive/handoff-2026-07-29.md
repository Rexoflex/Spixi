## Gotchas (this environment — additions from this session marked ★)
- Mount can't unlink (`rm`/`git checkout` fail) — overwrite via `git show HEAD:f > f`; `mv` works
  (that's the `_to_delete/` mechanism). Long node runs get KILLED on the device VM — generators
  fine, smoke = Damir local. **Cloud-container jsdom is NOT limited** (★ used for the #285
  reveal-cycle verification — see the harness recipe below).
- ★ Plain `git status` from the bridge strands a 0-byte `.git/index.lock` it can't unlink →
  **always `git --no-optional-locks`** for status/diff.
- ★ `device_stage_files` can serve STALE bytes for a path it staged before (same mtime cache key)
  — `cp` the file to a NEW name on-device and stage that to bust it.
- `build-shells.mjs all` overwrites the LEGACY `apps.html` + `wallet_send.html` (money page) —
  use `launch` or the no-arg default (17). ★ Its export guard fails the build if a shell
  destructures a symbol `spixi.iife.js` doesn't export — trust it (it caught a real one in #285).
- ★ `createButton` takes an icon ELEMENT (`icon('name')`), never a string — a string throws inside
  the fail-soft `executeUiCommand` catch = silent dead view. The bundle does NOT export `icon()`.
- ★ jsdom repro of a built shell (cloud container): load the built HTML, `beforeParse` inject
  `util.TextDecoder/TextEncoder` + a `matchMedia` stub, then drive C#-style bursts via
  `window.executeUiCommand(window.<handlerName>, ...args.map(b64))` — handler refs are globals,
  args are base64 (Utils.cs contract).
