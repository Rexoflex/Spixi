Light + dark where the row says so. iOS / Mac rows go to the office sheet (`docs/office-walk-sheet-v1.md`), not here. ⚠ The S20 C# (SingleChatPage · S11MediaRules · SpixiFlags · DevPage · S17MomentRules · SMoments · DtTitleBar\* · App.xaml.cs · ThemeManager) is UNCOMPILED for MAUI: the BUILD rows are its first compile — a build error is a batch bug, paste it. ## Set-up
- **(a) Patch + commit:** apply the patch and commit — see the delivery message (the commands are there).
- **(b) Windows:** F5 only, never `dotnet build` (#663). Close Visual Studio, then wipe first: `cmd /c rd /s /q "\\?\<repo>\Spixi\bin"` (a WebView2 file has a 261-char path; `Remove-Item` stops on it) and `Remove-Item -Recurse -Force Spixi\obj` (L139).
- **(c) Android:** close Visual Studio, wipe `Spixi\obj` + `Spixi\bin` (the same two commands; the html changed, #320/#449), then `dotnet build Spixi\Spixi.csproj -f net10.0-android -c Debug -t:Run`.
- **(d) Test data:** a chat with a large image and 70+ messages · a group · a received file offer (PDF 2–3 MB, auto-download off) and a sent file · payments in several states (sent, received, request in, request out, one declined) · a mini-app installed · a second device as the peer (on the S20 build for F-MARKS).
- **(e) Logs to paste:** the Android logcat lines `[FLAGS]` and `[MO]` (`adb logcat -d -v time | Select-String '\[FLAGS\]|\[MO\]'`), plus the full log saved as UTF-8.
- **(f) ON rows:** they need the welcome screen. Walk them on a device or Windows user with no account you need (Android: Settings › Apps › Spixi › Storage › Clear storage; Windows: Settings › Apps › Installed apps › Spixi › Advanced options › Reset). Restore brings back NO chats (#1420). After ON-C4: Account › Backup › Back up now (keep the file and the password), clear the data again, then walk ON-R1–R3 with that file.
- Moment rows (G-INSTALL-\*): Developer › Reset moment sheets, then restart, before EACH row. Grep the log for `[MO]`.
