Today shipped

What is wrong (small)

  • Grey tiles under a coloured entry. The row that opened the sheet has a blue disc; the two choices have grey medallions with black glyphs, and no chevron, so they read as info cards more than as buttons.
  • The words change on the next screen (“Spixi address” → “Ixian address”). Fixed on the screen side in 1·A.
  • The lead says what the two cards say. Acceptable: it is the one line under the art.
  • The example in the hint (“42Spox…M3rci98”) is a shortened address. It shows the format that 1·B’s error catches. Harmless; worth a look if the hint is ever edited.

Should it go straight to the field?

  • The screen and the sheet are not two entries to the same job: on a phone they are two steps (sheet, then screen). The only double is the scan button on the screen, which is a correct fallback.
  • Putting the field in the sheet (B) saves one step for the “paste” path. It costs a second implementation of the form inside a sheet, and the scan path still needs the screen. For a task done a few times per user, that is a lot of code for one tap.
  • Verdict: keep the sheet. A is a light polish.
