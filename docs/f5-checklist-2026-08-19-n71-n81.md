## 0. Before you build

⚠ **`src/components/theme-runtime.js` is a NEW file — `git add` it.** The bundle
build reads it. If it is missing, every shell loses `setTheme`.

C# changed → **wipe `Spixi\obj` and `Spixi\bin`** (#387). Both targets share them.

Everything below already ran clean in the cloud twin. Your run is the confirmation.

⚠ **PowerShell**: do NOT paste an annotated list. A trailing `(18 shells)` reads as an
unclosed expression, PowerShell swallows every following line as a continuation, and the
whole block dies on a parse error having run NOTHING. Paste this — it stops at the first
failure and keeps bundle-before-shells:

```powershell
$ErrorActionPreference = 'Continue'
foreach ($s in 'extract-strings','build-locales','build-strings-iife','build-demo-bundle','build-shells','i18n-lint','pseudo-locale-smoke','smoke-test') {
  Write-Host "== $s" -ForegroundColor Cyan
  node "scripts/$s.mjs"
  if ($LASTEXITCODE -ne 0) { Write-Host "STOPPED at $s (exit $LASTEXITCODE)" -ForegroundColor Red; break }
}
```

Then the build:

```powershell
Remove-Item -Recurse -Force Spixi\obj, Spixi\bin -ErrorAction SilentlyContinue
dotnet build Spixi\Spixi.csproj -f net10.0-android -c Release -t:Run
```
