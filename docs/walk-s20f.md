## Set-up
- **(a) Patch + commit:** apply `session20f.patch` and commit (the commands are in the delivery message). No C# changed in S20F; the only non-web file is `Spixi/Resources/Raw/lang/ru-ru.txt` (one typo).
- **(b) Windows:** F5 only, never `dotnet build` (#663). Close Visual Studio, then wipe first: `cmd /c rd /s /q "\\?\<repo>\Spixi\bin"` and `Remove-Item -Recurse -Force Spixi\obj` (L139).
- **(c) Android:** close Visual Studio, wipe `Spixi\obj` + `Spixi\bin` (the html changed, #320/#449), then `dotnet build Spixi\Spixi.csproj -f net10.0-android -c Debug -t:Run`.
- **(d) Test data:** a chat with a 5-photo group and 30+ messages · a group · a received file offer (auto-download off) · payments (request in / out) · app invites · a wallet with 50+ rows · 20+ downloaded files from several contacts · a second device as the peer.
- **(e) Logs to paste:** Android `adb logcat -d -v time | Select-String "\[DOWNLOADS\]|\[FLAGS\]"`, plus the full log saved as UTF-8.
- **(f) ON rows:** they need the welcome screen — walk them on a device / Windows user with no account you need (Android: Settings › Apps › Spixi › Storage › Clear storage; Windows: Settings › Apps › Spixi › Advanced options › Reset). ON-RT1 needs two data folders (see the row).
