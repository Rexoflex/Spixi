## 6 · Rules this session paid for

* **A profile's self time is not the boot's delta** (#917): the probe cost 25–71 ms on the profile and `load` moved
  13–20; the first number went into a docblock before the second was taken. Measure the thing you claim.
* **A height-only media query is not a landscape query** (#918): portrait with the keyboard up is under 500 px too.
* **The viewport is not the device** (#922): inside a two-pane column `(orientation: landscape)` is FALSE on a landscape
  phone. A rule about the phone's posture reads `screen.orientation`, not the window.
* **A fixed line count in a pin breaks the moment the thing it counts grows** (#920 ①): derive the banner.
* **An XML comment defeats a raw sweep exactly as a JS comment does** (#920 ③, #771): strip `<!-- -->` first.
* **"Proven to load" and "stamped" are different claims** (#920 README): the July session did the second.
* **State the dial you could not build** (#919): the by-sender mute is in the row, the spec and two walk rows,
