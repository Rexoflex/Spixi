## 6 · Lessons
- L130 A moment or prompt in an UNTRUSTED WebView must never write a setting: an ask/answer protocol is not proof of a user tap — route the choice to a trusted surface (#1340, #46 security r1).
- L131 "Seen at the grant" needs "ask only when it can show" — otherwise a granted sheet is lost to a tab switch or a reload (#46 r1).
- L132 A session in two places (C# and a shell) needs ONE clock: the wall clock, and an expiry the shell hears (#46 r2 / r3).
- L133 A default flip of a privacy switch turns every latent input path on for everyone — sanitize the peer-controlled value first (#1346, #46 security r3).
- L134 A pin with a hard ms threshold flakes when the bundle grows — measure its margin against the path it must exclude (#1350).
