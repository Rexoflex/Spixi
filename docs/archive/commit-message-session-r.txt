THE GATE RAN. CLAUDE.md has promised since 2026-08-15 that the redesign

THREE MAJORS NOBODY HAD FILED

- The remote-media auto-fetch was widened from two hosts to all of them. The
  baseline auto-loaded an <img> only for an anchored tenor/giphy URL. The
  redesign accepted any host, over http or https, on render, behind a gate that
  defaults ON and had no code anywhere that wrote its preference. A stranger's
  first message took the reader's IP, user agent and read time. Live on iOS and
  MacCatalyst; Android and Windows already refused the host at the platform
  layer.

- A zip-slip in account restore. The heal-Windows-backups loop converts a
  backslash into a separator, and on Android, iOS and MacCatalyst a backslash is
  a legal filename character. It runs before verifyWallet, so an attacker needs
  only the archive password.

- iOS granted camera and microphone to mini-app content with no prompt. The
  capture delegate read neither the origin nor the frame, and the handler is
  registered app-wide.

THE THREE ROWS THE GATE ALREADY CALLED OURS ARE CLOSED

  keyed on is a two-platform contract. Windows and MacCatalyst are NOT
