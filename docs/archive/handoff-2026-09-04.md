## 0 · ⚠⚠ THE LAUNCH BLOCKER — shipped copy that contradicts the architecture

`src/shells/chat.html:3435`, rendered at the top of **every conversation**:

> "Messages go straight from device to device, sealed with post-quantum encryption.
> **No server carries or stores them.** Every message exists only with you two, nowhere else."

**That is false whenever the recipient is offline.** `Ixian-Core/Streaming/OfflinePushMessages.cs`
POSTs to `https://ipn.ixian.io/v2/push.php` with `tag` = recipient address, `data` = the encrypted
message, `fa` = **sender address**. The message is held on that server until the recipient's device
calls `fetch.php`. So a server does carry and store it, and it observes **who sent to whom, and when**.

★ The **encryption** half is fine — the server holds ciphertext and cannot read it. It is the
**"no server"** sentence that is wrong, and it is the exact sentence a journalist or a regulator tests.

⚠ **This is a copy decision, so it is Damir's, not the next session's to make unasked.** A suggested
replacement is in `docs/privacy-workorder-2026-08-29.md` §P0. Changing it costs an i18n pass
(`secureNoticeText`, twelve locales). **Raise it on the first turn.**
