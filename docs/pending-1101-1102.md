## #1101 — Mac (and iPhone) CRASH after calls: SIGSEGV in -[AVAudioNode dealloc]

Seen: Mac walk 2026-10-01 ~20:52, after "a handful of calls". `Spixi quit unexpectedly`.
Native stack (terminal): `NSObject_Disposer.Drain → xamarin_release_managed_ref → -[AVAudioNode dealloc] →
AVAudioIONodeImpl::~AVAudioIONodeImpl → -[AVAudioClock dealloc] → AVAudioNodeImplBase::RemoveRenderObserver → SIGSEGV`.
Crash report on the Mac: `~/Library/Logs/DiagnosticReports/Spixi-2026-10-01-205231.ips`.

Mechanism: `SAudioPlayer` reads `audioEngine.OutputNode` (every buffer, for LastRenderTime) and `MainMixerNode`;
`SAudioRecorder` reads `audioRecorder.InputNode`. Each read creates a managed wrapper holding a retain on the IO node.
`stop()` disposes the ENGINE; the node wrappers stay alive until the GC finalizer releases them on the main thread —
after the engine is gone — and the IO node's destructor touches the freed engine. Same code in Platforms/iOS (the two
copies are kept identical), so the iPhone can crash the same way.

Fix (the script below): hold `outputNode` / `mainMixer` / `inputNode` in fields, read LastRenderTime / player time in
`using` blocks, dispose the node wrappers in `stop()` AFTER Stop/Reset and BEFORE the engine; also on the Mac recorder's
"no usable microphone" throw path. Tested on a copy: applies to all 4 files, all 4 parse (tree-sitter).
Owed: a smoke pin (source pin: node wrapper disposed before `Dispose()` of the engine, in all 4 files) + a deliberate
break; Mac + iPhone walk row: 6 calls (answer, talk, hang up) + 2 min idle → no crash.

import sys
def patch(p, pairs, optional=()):
    s = open(p, encoding='utf-8-sig').read()
    bom = open(p, 'rb').read(3) == b'\xef\xbb\xbf'
    for old, new in pairs:
        if s.count(old) != 1:
            sys.exit("STOP: %s: pattern not found once: %s" % (p, old[:60]))
        s = s.replace(old, new)
    for old, new in optional:
        if s.count(old) == 1:
            s = s.replace(old, new)
    open(p, 'w', encoding='utf-8-sig' if bom else 'utf-8').write(s)
    print("patched", p)

NOTE = "// ★ #1101 (Mac walk crash 2026-10-01: SIGSEGV in -[AVAudioNode dealloc] → AVAudioClock → RemoveRenderObserver):\n"
for plat in ("MacCatalyst", "iOS"):
    patch("Spixi/Platforms/%s/SAudioPlayer.cs" % plat, [
        ("        private AVAudioFormat inputAudioFormat = null;",
         "        private AVAudioFormat inputAudioFormat = null;\n"
         "        " + NOTE +
         "        // every AVAudioEngine.OutputNode / MainMixerNode read makes a managed wrapper that holds a retain; if the GC\n"
         "        // releases it AFTER the engine is gone, the IO node's destructor touches the freed engine. Hold them once and\n"
         "        // dispose them in stop() BEFORE the engine.\n"
         "        private AVAudioOutputNode outputNode = null;\n"
         "        private AVAudioMixerNode mainMixer = null;"),
        ("            audioEngine.Connect(timePitchNode, audioEngine.MainMixerNode, inputAudioFormat);",
         "            mainMixer = audioEngine.MainMixerNode;\n"
         "            outputNode = audioEngine.OutputNode;\n"
         "            audioEngine.Connect(timePitchNode, mainMixer, inputAudioFormat);"),
        ("            var lastRenderTime = audioEngine.OutputNode.LastRenderTime;\n"
         "            if (lastRenderTime != null)\n"
         "            {\n"
         "                var playerTime = audioPlayer.GetPlayerTimeFromNodeTime(lastRenderTime);\n"
         "                if (playerTime != null)\n"
         "                    playedFrames = playerTime.SampleTime;\n"
         "            }",
         "            var outNode = outputNode;\n"
         "            using (var lastRenderTime = outNode?.LastRenderTime)\n"
         "            {\n"
         "                if (lastRenderTime != null)\n"
         "                {\n"
         "                    using (var playerTime = audioPlayer.GetPlayerTimeFromNodeTime(lastRenderTime))\n"
         "                    {\n"
         "                        if (playerTime != null)\n"
         "                            playedFrames = playerTime.SampleTime;\n"
         "                    }\n"
         "                }\n"
         "            }"),
        ("                audioEngine.Dispose();",
         "                // ★ #1101: release our node wrappers while the engine is still alive\n"
         "                outputNode?.Dispose();\n"
         "                outputNode = null;\n"
         "                mainMixer?.Dispose();\n"
         "                mainMixer = null;\n"
         "                audioEngine.Dispose();"),
    ])
    patch("Spixi/Platforms/%s/SAudioRecorder.cs" % plat, [
        ("        private AVAudioEngine audioRecorder = null;",
         "        private AVAudioEngine audioRecorder = null;\n"
         "        " + NOTE +
         "        // the InputNode wrapper must be released BEFORE the engine (see SAudioPlayer). Held once, disposed in stop().\n"
         "        private AVAudioInputNode inputNode = null;"),
        ("            recordingFormat = audioRecorder.InputNode.GetBusOutputFormat(0);",
         "            inputNode = audioRecorder.InputNode;\n"
         "            recordingFormat = inputNode.GetBusOutputFormat(0);"),
        ("            audioRecorder.InputNode.InstallTapOnBus(0, bufferSize, recordingFormat, onDataAvailable);",
         "            inputNode.InstallTapOnBus(0, bufferSize, recordingFormat, onDataAvailable);"),
        ("                    audioRecorder.InputNode.RemoveTapOnBus(0);",
         "                    inputNode?.RemoveTapOnBus(0);"),
        ("                audioRecorder.Dispose();",
         "                inputNode?.Dispose();   // ★ #1101: before the engine\n"
         "                inputNode = null;\n"
         "                audioRecorder.Dispose();"),
    ], optional=[
        ("                throw new Exception(\"No usable microphone input format: \" + recordingFormat);",
         "                inputNode?.Dispose();   // ★ #1101: never leave the node wrapper to the GC after a failed start\n"
