  • -p:RuntimeIdentifier=ios-arm64 is required. Without it, Debug builds a Simulator app.
  • Do not add -p:CodesignKey (the certificate name does not match) or -p:CodesignProvision (it also re-signs the extension with the wrong profile). Never add -p:CodesignEntitlements= (it removes push).
  • Profiles in that folder: an App Development profile for com.ixilabs.spixi with Push + App Group group.com.ixilabs.spixi, and one for com.ixilabs.spixi.Spixi-PushService with the same App Group. These worked on 2026-09-24 and 09-27.
  • This is the first iOS compile of #1040–#1082 C# (CallPage, VoIPManager, the recorders, SPlatformUtils, SpixiContentPage, HomePage, SettingsPage, SingleChatPage). A compile error: paste the first error line in the chat. It is fixed before the walk.
