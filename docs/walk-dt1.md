# Walk DT-1 P1 — the desktop chat list polish + the Windows title bar

Added DT-1 P1 (2026-10-13, DECISIONS #1380–#1389; DT-SWIPE needs the second patch `dt1-swipe.patch`). Walk on the DT-1 P1 build (base `c277ec5f`, Session 19). The DT-1 C# (DtTitleBar · DtTitleBarRules · App.CreateWindow · the Windows window mapper · ThemeManager · SpixiFlags · DevPage) is UNCOMPILED for MAUI: DT1-BUILD-W is its first compile. Platforms: Windows (W) · Android (A). The Mac list rows ride the P2 Mac walk. Logs: grep `[DT]`, `[FLAGS] dttitlebar`. The DT-TB rows are the STOP-rule spike for the title bar: a failed row on the default way → walk DT-TB-W2. The interactive sheet is the published Artifact "Spixi Desktop DT-1 Walk"; this file is its source.
