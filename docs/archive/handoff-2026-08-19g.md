## 3. ★ What is now KNOWN that was not before

1. **N68 is root-caused.** `System.AggregateException:
   TaskExceptionHolder_UnhandledException (Operation Canceled)` →
   `SocketException (125)` at **`TcpClient.CompleteConnectAsync`**, 0.3 s after a
   connect timeout. That name means an exception NOBODY OBSERVED, re-raised by the
   finalizer — which on Android is exactly a native dialog over a still-running app.
   **Core-side**, which is why no FE change ever moved it. Fix shape: observe the task
   so a cancelled connect cannot reach the finalizer. Logcat is no longer required.
2. **N69(b) is PROVEN** by a controlled comparison in one session: a request sent while
   disconnected was a dud, the identical action once connected went through.
3. **N69 lead** — even in a healthy session the STREAM (S2) bootstrap fails three times
   and lands only at +6 s, while DLT clients are up in ~2 s. Contact requests ride the
   stream layer. The "Connecting…" indicator reads DLT and is truthful; the layer the
   request needs is the slower, noisier one.
4. **N77 is answered and is NOT an FE item** — see §4.

## 4. ★ N77 — the measurement that deleted the feature

Damir asked to disable the chat row while the community bot loads and toast when ready.
The probe says do not build it.

One join, on a fresh account, produced **6690 log lines**:

* **5682** (85%) — `Attempting to add a duplicate message (code: s2data)` to **ONE**
  relay (`193.95.221.67:15235`) in **68 s**. Every other endpoint in the whole log:
  **9** lines between them.
* **478** signature-verification failures — `msgDelete` ×186 (all from the bot),
  `avatar` ×292 (dozens of participants), over **94 s**.
* **17** `CryptographicException: RSA_DecryptWrongSize` at `MessageCrypto.decryptRSA1`
  ← `StreamMessage.decrypt` ← `CoreStreamProcessor.receiveData`.

The probe read `n=0` throughout, and **that is the result**: essentially nothing reaches
the shell, so no FE loading state could touch it. The FE render path was already optimal
(#413 — the burst suppresses every render and paints once).
⚠ **Do not build a loading affordance until the S2 side is fixed** — there would be
nothing left to hide.
