## 5 · Rules this session paid for

* **A rule anchored to the verb that usually precedes a state holds until the state arrives another
  way** (#902). Anchor it to the state, or to the caller.
* **A reviewer's fix is a hypothesis too** (#902): the one-liner offered for the MAJOR would have
  made a chat's Details button close the chat.
* **Reuse moves the invariants that construction was holding for free** (#903): "a view is a
  document" and "one thread renders this page" were both true only because every tap built a page.
* **`MainThread.BeginInvokeOnMainThread` is inline on the main thread and a post off it** (#903) —
  so "both threads call the same marshalling function" does not mean "in order".
* **"Derived" that matches one spelling is a list** (#906, #798 again — and the repair was one too).
* **A kill only counts if the baseline is green in the same root** (#906, #811 in the instrument).
* **A status row records what a session FOUND, not what the tree IS** (#906): I wrote "the media
  pref has no writer" into a legal proposal from Session R's row; Session R had built the writer.
