Dark received bubbles: three options

Damir 22:48: "Received bubbles, I thought maybe darker more saturated? … And do we do the canvases slightly darker in dark mode?" Built S19 chat.html (scratch copy + override CSS), dark theme, mobile 390 px, every canvas. Tap a frame for the full image.

  • A — The current S19 build: bubble = canvas mid + 12 % white; Aurora / Dusk / Ocean grounds L×0.9 C×0.9.
  • B — Bubble darker + more saturated (OKLCH L 0.30–0.32, C = 1.5 × the canvas mid chroma, canvas hue); every dark ground L×0.85 (OKLab, C kept, gamut-mapped).
  • C — B's bubble recipe one step darker (L 0.28–0.30) on grounds L×0.75.

Every option and canvas passes every check: text ≥ 7, meta ≥ 4.5, bubble lighter than every ground stop by ≥ 1.2, quote one step darker (1.20–1.29), sender names ≥ 4.5, reply labels and reply text ≥ 4.5 on the quote. Each quote is the bubble scaled in OKLab until it is 1.25 : 1 darker. Mist is neutral, so "more saturated" does not change it much; in B and C, Mist only gets darker.

Recommendation: B. It gives the darker, richer bubble and a visibly deeper ground on all seven canvases, and each canvas keeps its colour. C takes Mist, Meadow and Spixi close to black. In C the pattern drops about 5 % more (C needs pattern alpha ×1.16–1.22 to match A; B needs ×1.09–1.15).
