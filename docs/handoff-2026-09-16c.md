## ★ Three things this session learned the hard way

1. **A Figma MCP asset URL is a picture of the node on its page.** The four glyphs pulled that way
   carried the page rect, the canvas paths and `id`s. Only a frame or node EXPORT from Figma is a glyph.
2. **The bridge stamps a C2PA manifest into any SVG it writes** — by content, not by name — and can
   report the write as rejected while the bytes are on disk. SVGs travel zipped; every committed file
   is re-staged and compared before it is called landed.
3. **#858's second "removable item" is not removable** — it is a measured trade #345 already made
   (per-shell CSS inline because `generatePage` is linear in inlined size and the CSS is not shared
   within a shell). #867 records it so nobody "cleans it up".
