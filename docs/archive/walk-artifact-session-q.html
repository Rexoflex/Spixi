What changed, in one paragraph

Nothing was added. The screens, the capabilities and the verbs all already existed and already shipped — on desktop, since #243 / #267 / #341. Each of those batches wrote “mobile keeps the push”, and each wrote it for conservatism rather than for a reason about phones. The capability flags were being sent to the phone the whole time (SettingsPage.onLoad pushes the caps outside its if (paneMode) block, and always has). Only the shell refused to use them. So the fix is paneMode && deleted from three guards, and the pushed pages stay as the fallback for an exe that sends no capability.

The pre-warm was considered for these three pages and rejected. #800's spare is priced at ~15 MB each (#803), so three would have been ~45 MB — to make a boot the app still pays for happen earlier. This removes the boot.
