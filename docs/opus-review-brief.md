## The loop (repeat until CLEAN)

1. **Audit.** Spawn read-only adversarial agents over disjoint scopes
   (components+css / demo pages+wiring / scripts+generators). Findings need
   file:line. Hunt specifically: unhandled null/empty/overflow states, latch
   and re-entry bugs on async buttons, listener/observer leaks, focus traps
   broken by early return, RTL and long-string overflow, dead code, duplicated
   logic, raw values where a token exists, contract violations (list below).
2. **Classify.** MAJOR (bug/edge case/contract breach) and MINOR (cleanup) get
   fixed. Architectural changes → 🟡 DECISIONS row + ask Damir first.
3. **Fix.** Targeted edits only. For every bug fixed, add a smoke assertion in
   `scripts/smoke-test.mjs` that would have caught it (regression guard).
4. **Verify.** Build + smoke (see environment rules). Red → fix → re-run.
5. **Review.** Fresh adversarial reviewer agent over the round's diff.
   Findings → back to 3. Exit only when a full review pass reports **zero
   findings AND smoke is green**.

## Contracts that bite

- `setPaymentStatus(row, patch)` takes an OBJECT patch (a bare string is a
  silent no-op, #140②) and **returns a NEW row** — adopt it, re-wire menus.
- Latched buttons are released by re-render, never re-enabled in place;
  callbacks use the `(payload, ctrl)` contract, one-shot per attempt.
- `status:'failed'` rows are re-created, not patched.
- Fully-locked confirms: Esc/scrim/Cancel dead in-flight; sync throws in shell
  callbacks must route to the fail path (#141-m4).
- Whatever appends a chat row keeps the typing pill last (`keepTypingLast`, #140④).
- Amounts through `formatIxiAmount` — ≤2 decimals, truncated never rounded.
- Flex items that contain nowrap text need `min-width:0` (#140③) — jsdom is
  layout-blind, so overflow bugs need reasoning, not just tests.
