## Set-up
- **(0) ★ COPY YOUR DATA FIRST (L149, after the ON-RT1 loss).** Before ANY row that touches account data (welcome, create, restore, retry, delete account): close Spixi, then COPY the whole data folder. Windows: `Copy-Item -Recurse "$env:USERPROFILE\Documents\Spixi" "$env:USERPROFILE\Documents\Spixi-copy-$(Get-Date -Format yyyyMMdd-HHmm)"`. Android: use a test phone / a test account only. Never replace, move or rename a `wallet.ixi` in a folder that holds contacts you need.
- **(a) Patch + commit:** apply `session20g.patch` and commit (commands in the delivery message). C# changed: `HomePage` · `LaunchPage` · `SettingsPage` · `RestoreMoves` · `SpixiFlags` + 14 `lang/*.txt`.
- **(b) Windows:** F5 only, never `dotnet build` (#663). Close Visual Studio, wipe `Spixi\bin` (`cmd /c rd /s /q "\\?\<repo>\Spixi\bin"`) + `Spixi\obj` first (L139).
- **(c) Android:** close Visual Studio, wipe `Spixi\obj` + `Spixi\bin`, then `dotnet build Spixi\Spixi.csproj -f net10.0-android -c Debug -t:Run`.
- **(d) Welcome screen on Windows WITHOUT touching your account:** after (0), close Spixi, RENAME `Documents\Spixi` to `Documents\Spixi-mine`, F5 → an empty folder = welcome. When done: close Spixi, rename the new `Documents\Spixi` to `Documents\Spixi-test`, rename `Spixi-mine` back to `Spixi`. Android: Settings › Apps › Spixi › Storage › Clear storage on a TEST phone.
- **(e) Logs:** Windows `Documents\Spixi\ixian.log` (lines `[FLAGS]`, `[RESTORE]`); Android `adb logcat -d -v time | Select-String "\[FLAGS\]|\[RESTORE\]|\[DOWNLOADS\]"`.
