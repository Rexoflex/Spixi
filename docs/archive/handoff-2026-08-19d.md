## 3. Owed / open after this batch

1. ★ **N73 covers Android only.** `SPlatformUtils.setEdgeToEdge` is a no-op on
   iOS and MacCatalyst, and nothing in the tree sets `UIStatusBarStyle` or
   `OverrideUserInterfaceStyle`. So on an iPhone in light mode the status-bar
   glyphs are still drawn dark over the fixed-dark launch and lock screens.
   That is pre-existing, not introduced here, but N73 cannot be called closed
   until someone looks at it on a device. It needs a `UIViewController`
   override, which is new surface — **get a screenshot first** (#294).
2. **The Android inset work (AND-7) is still gated on probe numbers.** This
   batch deliberately did not touch page padding or `env(safe-area-inset-*)`.
3. **The join CTA latches before delivery.** If `joinBot()` fails C#-side, the
   CTA is inert for that document with no visible answer to the first tap. The
   safe failure was chosen on purpose (never add the bot twice); if Damir wants
   feedback, it is a spinner on the button, not a change of latch.
4. **The launch ground colour is a dial.** `#1b163c` (the top of
   `--gradient-launch`) in three places: `src/shells/launch.html` twice and
   `SpixiContentPage.surfaceColorStringFor`.
5. Back from the **unlock** view now reaches welcome (it used to pop a root
   page, which did nothing). Both doors there refuse while a wallet exists.

**★ New gotcha (#391): editing a file with a script can flip its line endings.**

rewrite turns 30 real lines into 900 diff lines. Check before you hand over.
