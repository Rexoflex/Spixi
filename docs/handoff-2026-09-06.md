## What shipped

Two levers against the same half second, in ONE build (Damir's call — the phone reads one
number, the stamps stay separable).

**The pre-warm (#800).** A `SingleChatPage` with no friend is staged hidden in HomePage's grid
and its shell booted while the user is still on the chats list. On tap, `pushSpareChat` hands it
the friend and the same overlay path presents the stage it already holds. #796 measured what
that moves off the critical path: WebView creation (72–79 ms) + parse (102–109 ms) of a ~315 ms
median open. **Every refusal falls back to today's construct-and-stage push** — the spare is
never the only way into a conversation.

**The batch transport (#801).** `loadMessages` collects the whole load burst into one `UiBatch`
and crosses the bridge once as `addMessages(json, "append")`, then `messagesDone` ends the
shell's render burst by SIGNAL instead of by its 250 ms timer. Both transports stay live on both
ends: an old exe still paints on the timer. `position: "prepend"` is accepted and never derives
the unread boundary — the shell contract for B2 is complete; this exe sends only `append`.

**NOT built, as decisions:** B2 (prepend on load-more) and B4 (`Config.messagesToLoad`) — see
#801. ⛔ #779 (the retained warm WebView) stays parked with the lead.
