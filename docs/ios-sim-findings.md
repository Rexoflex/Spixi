**Crash triage 2026-07-22 (.ips analysis):** iOS-5, iOS-7 and iOS-9 are ONE bug — a managed exception thrown inside `SPushService.NotificationDelegate.WillPresentNotification`, reached via OneSignal notification-swizzling on every FOREGROUND presentation (attach-moment message, contact request, incoming call — the trigger was the notification, not the feature). `DidReceiveNotificationResponse` had a try/catch; `WillPresentNotification` did not — a managed exception escaping a native callback is an uncaught NSException → abort. Both callbacks now guarded (#280). Underlying exception surfaces in the log on next repro — root-cause row to follow.
