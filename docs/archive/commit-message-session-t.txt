mechanism. PSS reads as growth (261 → 342 → 362 MB) but swap falls 140 → 46 →

so 511 MB over a ~400 MB floor is a transient SPIKE, not accumulation. The
defect stays OPEN (AND-40); the hypothesis is closed.
