## 5 · Bridge notes (this session paid for them)

* Plain `git` writes on the mounted folder leave `.git/index.lock` and `.git/objects/*/tmp_obj_*` behind unless
  delete permission is granted — ask for it ONCE (`device_request_delete_permission` on the repo root) before any
  commit, or every git write strands a lock.
* A backgrounded `smoke-test.mjs` dies with the call. To run ONE block: splice lines 1–330 (the helpers) + the
  block into a temp `.mjs` under `scripts/`, run it, delete it.
* Stage from a delivery tarball's own bytes with `git hash-object -w --path=<p>` + `git update-index --index-info`
  when the working tree has moved on — that is how `c0711262` stayed exactly the delivered AE.
