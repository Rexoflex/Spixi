Speed batch 1a: four speed switches and the dev image seed (C# only)

C# only: no file under src/, Spixi/Resources/Raw/html/, scripts/device/
or .github/ is changed, and not Spixi/Spixi.csproj. No new bridge verb
and no new push. Each change has its own switch with the old path as
the fallback. The C# is UNCOMPILED: the Windows job of redesign-ci is
the first compile; the Android build is the first compile of every
Android-only arm.

- The four switches (Spixi/Utils/SpixiFlags.cs, PerfB1Rules.cs,
  Spixi/Pages/Dev/DevPage.xaml.cs): flagWarmOnIdle, flagSpareRearm,
  flagPhoneNoEmptyDetail (ON by default; a stored 0 acts only in dev
  mode) and flagSpareKeepShortSleep (opt-in: absent = OFF, a stored 1
  acts only in dev mode, OFF at once on both ways out of dev mode). One
  log line "[FLAGS] warmidle= sparerearm= sparekeep= noemptydetail=".
  Four forms of the existing dev verb ixian:devflash. The Developer
  screen has no rows for them yet (DECISIONS 1569).
- P-12 WarmOnIdle (packet P38; WarmIdleRules.cs, MainActivity.cs,
  SpixiContentPage.cs, HomePage.xaml.cs): on Android a hidden WebView
  (the spare chat page, the parked Account page) starts its boot only
  after 1200 ms without a touch and at least 900 ms after the other
  hidden boot. The touch stamp is one static long that holds a time.
- P-11 switch 1 SpareRearm (packet P39; SpareRearmRules.cs,
  SpixiContentPage.cs, HomePage.xaml.cs): after a drop (sleep, theme,
  language, reload, devmode) the spare chat page is armed again; a
  quiet resume schedules the warm at the resume + 1800 ms; never under
  a lock and never in the background.
- P-11 switch 2 SpareKeepShortSleep (packet P40; SpareKeepRules.cs,
  App.xaml.cs, SpixiContentPage.cs; Android only, opt-in): the spare
  chat page is kept for up to 3 minutes in the background, never with
  the app lock on, and is handed to a chat open only after a
  document.readyState answer from its own WebView at the return. The
  reason for the drop at sleep: docs/perfb1-spare-drop-reason.md.
- P-13 PhoneNoEmptyDetail (packet P41; EmptyDetailRules.cs,
  HomePage.xaml.cs): a phone display does not build the empty right
  pane at start; the first wide layout builds it once.
- The dev image seed (packet P42; SDevSeed.cs, SDevSeedPlan.cs, dev
  builds only, inside the SPIXI_DEV_COEXIST symbol): seed indexes 50,
  51, 52 = Seed 51-53 with 46 photos made in code; the album is in
  Seed 52; fixed message times; a file is kept or deleted only with
  proof by content; the log lines carry the exception type only (also
  SettingsPage.xaml.cs). Seed 01-50 are unchanged. The account wipe
  calls SpixiFlags.leaveDevMode().
