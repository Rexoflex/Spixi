Session V - the icon gate that did not exist, the Add-contact chooser sheet, the contact-details read (#862-#864)

#862 builds the cheapest gate on the board and it failed in three ways nobody had listed.
`generate-icons --check` regenerates in memory and compares byte-for-byte with the two
committed registries; GATE 63 asserts it runs green, plus four derived sweeps over the
sources. Building it found:

  - there is no `stroke-width` to sweep: Figma outlines the strokes, so the weight is read
    off the round-cap quarter-circle radius instead. Every 2026-09-10 export measures 1.50,
    every older stroke glyph 2.00; the expected value is the mode of the set, never a literal.
  - the re-export says fill="black" where the old files say #131415. The generator themed
    only #131415 and warned only on #hex, so running it as it stood would have shipped 79
    glyphs that stay black in dark mode with no warning - and checks-l already ships that
    way. The generator now themes every spelling of ink and warns on any unthemed paint.
  - apps.svg and messages.svg are byte-identical to their -filled twins and were never read
    by the generator: dead, not shadowing. Removed.

Ten stroke glyphs still carried the old weight when the gate first ran; it named them. Damir
re-exported the whole Figma frame at 1.50, added the four that were missing from Figma
(message-plus phone-end alert-small layout-grid) and removed the three that nothing used
(checks-l phone-done user-pentagon). 91 glyphs, one weight, one ink, --check green.
Six mutations, six kills; the gate-21 ORDER pins still hold.
