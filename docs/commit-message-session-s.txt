turned out to own something nobody had written down.

#811 THE THREE "STILL JANKY" ACCOUNT ROWS — the premise did not survive.
Backup / Change password / Downloads ARE #804, and #804 is in the tree. Checked
four ways: the source guards, the BUILT shell plus a green build-shells --check,
SettingsPage declaring AND pushing the caps outside the paneMode block, and the
one that could still have left it inert — bridge.cap() reads an SPIXI_ENV no
shell sets, so the route lives on setCaps mutating bridge.capabilities in place,
proven by BOOTING the built shell and tapping the rows.

Measured on the built shell in Chromium at 432x900 @2.5 through the real
executeUiCommand wire: How-to-use 5.1ms of script, Backup 5.2, Change password
5.3, Downloads 29.0 — and Downloads scales, 6.6 at zero files to 58.9 at 100. At
zero files it costs what the control costs; the whole term is the list, and
loadDownloads sends one addFile marshal per file on the UI thread, fired at the
START of the 300ms slide. The two rows named first are the two with no
measurable cost. Nothing behavioural was built (#294); the batch transport is
specified and gated on one fact nobody has: the file count.

What shipped instead is the instrument — [CDPERF] settings-sub (build / paint /
list), one hook on a view CHANGE, console.warn never .info (#751) — and GATE 44,
the pin four dead gates asked for, which EXECUTES strip-release.mjs through a
symlinked path.

#812 M13 — the code half was already closed, and the sweep that proved it found
a different defect in every shell. Every built shell booted under ?lang=pseudo,
plus a data-fed pass through the real wire because the surfaces named render
nothing until C# pushes. Verdict: no visible English left; M13's code half closed
at #269 the day AFTER the F5 that recorded the residual, and the roadmap row was
never updated. What the sweep DID find: the static a11y labels in boot markup —
16x "Loading", the chat log's "Messages" — plus createTopbar's backLabel and
createBottomNav's ariaLabel defaulting to the English LITERAL. A German user's
screen reader said "Back" and "Loading" while the dictionary held "Zurück" and
"Wird geladen". Invisible to both gates. Fixed with one mechanism; extract-strings
was taught the new one, because a mechanism the sweep cannot see is a key that
can never be translated. 786 -> 788 keys.
