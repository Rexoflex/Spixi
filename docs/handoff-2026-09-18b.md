## 4 · Rules that bit this session (add to yours)

* **A runner whose harness differs from the suite's proves less than the suite.** My scratch runner's `load` swallowed jsdomErrors; the suite's did not, and it failed the run on a real `file:` fetch my synthetic events had hidden (after5). The pin now runs in the BUILT shell where the payload really is, and declares the one miss it means (`load(file, { expectErrors })`).
* **jsdom's interceptors never see `file:` URLs** (probed) — a `file:` subresource can only be served from where the document really is.
* **A `file://` document cannot fetch a font beside itself** — Chromium serialises the origin as `null`; a classic `<script>` is not CORS-gated. This will bite any future asset that is fetched, not scripted.
* **"Contrast unchanged" is a claim about luminance** — moving a primitive by hue moves every ratio that reads it; re-measure, do not assert (auditor A).
* **A probe's unknown is not a no.** The first cut loaded the font on an unanswered probe; 'unknown' must refuse (auditor B).
* **A derived pin that passes an element with NO hover is vacuous** — unparsed = fail (reviewer).
* The container is the suite runner (#882 ①): `tar` from `git ls-files` (a whole-tree tar was 544 MB of untracked debris), `npm i --no-save jsdom eslint globals tree-sitter tree-sitter-c-sharp` ALL TOGETHER, ~6 min a run on this tree when nothing competes (three stale runs made it 35). Kill a stale run by PID, never `pkill -f` from inside a command that matches itself (exit 144).
* `git --no-optional-locks status` on the VM. A "written" that is not on disk after a reconnect → read the hash back.
