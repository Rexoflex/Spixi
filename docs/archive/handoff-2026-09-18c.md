## 3 · Two lessons worth keeping

* **A grep for a retired token finds the pins that NAME it and misses the pins that COUNT it.** Searching the
  suite for `spixi.chat.glass` returned one site. The real second half was `Session P L1·12`, which never
  spells the key — it derives the head script's key list and asserts `headKeys.length === 5`. It went red in
  both halves on the first full run, which is exactly its job. When you retire a thing, run the suite before
  you believe your grep.
* **A render with no subject is a pin with no mutation** (Session S #811, and it bit again). The first fade
  render scrolled a nine-message conversation that never overflowed the viewport, so no bubble was ever under
  the composer and all four panels were identical. The guard asserted the overlap and aborted. Keep that
  assert in any render you make.
