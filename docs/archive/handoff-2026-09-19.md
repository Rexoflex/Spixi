## 4 · The next batch, already scoped — and it is NOT two token edits

Damir: *"fix the gap between grouped messages from the same user 2px instead of 1px, and slightly
reduce the size of the tail in chat."*

**The gap is a one-token dial and a REVERT.** `--bubble-gap-inner: 1px` (`tokens.css:1135`) → `2px`.
Its own comment records the history: it was 2px at dial C, 3px before that. One pin re-bases —
`smoke-test.mjs:24264` asserts the literal `'1px'`, and its comment carries the Session T story, so
extend it rather than overwrite it.

⚠ **The tail is NOT a token edit, and this is the trap.** `--bubble-tail: 8px` /
`--bubble-tail-h: 13px` set the BOX, but the shape is **four hard-coded `clip-path` values in
absolute pixels**, drawn for a 9 × 13 box (width = tail + 1, the seam overlap):

| rule | path |
|---|---|
| LTR received | `M9 0 L2.2 0 Q0 0.2 0.5 2.2 Q3.4 8.2 8 13 L9 13 Z` |
| LTR sent | `M0 0 L6.8 0 Q9 0.2 8.5 2.2 Q5.6 8.2 1 13 L0 13 Z` |
| RTL received | the sent path |
| RTL sent | the received path |

Shrink the tokens without redrawing all four and the tail is a 9 × 13 shape clipped inside a
smaller box — a cut-off flag, not a smaller tail. All four are pinned at `smoke-test.mjs:24303`,
along with `width: calc(var(--bubble-tail) + 1px)`. Redraw proportionally, re-base that pin, and
**render both directions in both themes before pinning** — this is a shape, and a number in a
docblock is not evidence about a shape.

Also read before touching either: `message-bubble.css:46-58` records why the row inset no longer
carries a tail term (Damir's own dial), and `GATE 49` (`smoke-test.mjs:31605`) fails if it comes
back. The tail is positioned at `-1 × --bubble-tail`, so it follows the body automatically.
